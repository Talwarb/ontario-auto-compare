# MapleRate — Ontario Auto Insurance Comparison Demo

Static, responsive starter site with an interactive browser-only quote demo, illustrative comparison cards, coverage education, SEO metadata, favicon, privacy and terms pages.

## Important limitations
- All prices are fictional illustrative examples, not personalized estimates or live insurer quotes.
- No insurance company integrations, live prices, lead submission, backend, or customer database.
- No user input is transmitted by application code.
- The MapleRate name is provisional; check domain/trademark availability.
- Before commercial launch: configure real business/contact details, verify Ontario insurance regulatory requirements and brokerage/insurer permissions, arrange secure authorized quote integrations, and obtain privacy/legal review.

## Publish with GitHub and Netlify
1. Create a new GitHub repository, e.g. `ontario-auto-compare`.
2. Upload the files **inside** this directory to the repository root (index.html must be at root).
3. In Netlify, choose **Add new project → Import an existing project → GitHub**, authorize GitHub, and select the repository.
4. Build command: leave blank. Publish directory: `.`. Deploy.
5. Open the generated `*.netlify.app` URL and test on mobile.
6. Connect a custom domain in Netlify → Domain management. Confirm DNS as instructed by Netlify.
7. Replace placeholder contact and owner details. Add your final site URL as a canonical URL, sitemap.xml, and Google Search Console property. Submit sitemap after domain setup.
